This folder contains:
- `.github/dependabot.yml` - configuration file for [Dependabot](https://docs.github.com/en/code-security/tutorials/secure-your-dependencies/dependabot-quickstart-guide)
which you can use in your project if you put it on GitHub. Dependabot automatically **checks for updates** to your dependencies 
(NuGet packages, _including BepInEx packages!_, and GitHub Actions) and creates pull requests to update them.
